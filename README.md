# Brian Covarrubias

Independent researcher and creator of **CEYO — Certifiable Evidentiary Yield for AI Operations**.

My work focuses on evidentiary infrastructure for consequential AI and autonomous systems: deterministic artifact generation, cryptographic integrity, independent verification, trust architecture, constrained disclosure, and the institutional conditions required for later review.

CEYO is being developed as an independent evidence layer rather than a model-internal governance function. Its purpose is to let later reviewers verify defined properties of sealed AI-operation records without requiring access to model weights or proprietary system internals.

## CEYO repositories

- `NDR-US/ceyo-protocol` — canonical public protocol specification and reference implementation
- `NDR-US/ceyo-core` — private R&D, target architecture, security/governance/legal/product research
- `NDR-US/ceyo-decision-verification-demo` — public protocol demonstration
- `NDR-US/ceyo-site` — public presentation layer

CEYO is under active development. The current public reference profile is intentionally distinguished from the broader target architecture so that future-state design is not confused with already implemented guarantees.
